# Security Policy

## Supported Versions
This repository currently supports the `main` branch.

## Reporting a Vulnerability
If you find a security issue in TrendPulse AI, please open a private security advisory or contact the repository owner directly instead of creating a public issue.

Please include:
- a clear description of the issue
- the affected file or endpoint
- steps to reproduce
- any relevant logs or screenshots

We will review and respond as quickly as possible.
