# Contributing to TrendPulse AI

Thanks for helping improve TrendPulse AI.

## Local setup
1. Fork the repository.
2. Create a feature branch from `main`.
3. Run the backend and frontend locally.
4. Make focused changes with clear commit messages.
5. Verify the frontend build and backend tests before opening a pull request.

## Quality expectations
- Keep changes small and reviewable.
- Add or update tests when behavior changes.
- Prefer clear names and simple, maintainable code.
- Match the existing formatting and linting rules.

## Pull requests
- Describe what changed and why.
- Link to any related issue.
- Include screenshots for UI changes when helpful.
- Confirm that CI passes before requesting review.
